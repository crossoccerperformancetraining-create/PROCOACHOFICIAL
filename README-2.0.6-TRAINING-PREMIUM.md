# ProCoach 2.0.6 — Plano de Treino Premium

Versão construída sobre a 2.0.5.2 Stable Access + Match Day.

## Plano de Treino Premium
- Ficha CAMPO e ACADEMIA no mesmo módulo.
- Barra de sequência oficial por blocos.
- Check-in lateral com PSQ, prontidão, dor e limitações.
- Exercícios com até duas imagens/fases, vídeo, séries, reps/tempo, cadência, descanso, PSE, carga/dimensão, descrição e dicas.
- Modelos reutilizáveis de treino.
- Integração com Biblioteca existente.
- Envio para Equipe, um atleta, atletas específicos ou grupo salvo.
- O Athlete recebe o plano como treino guiado no Modo Play.
- PDF Premium dedicado com identidade navy/laranja, sequência, check-in, blocos e registro final.

## Campo
Ativação/Aquecimento → Técnico/Tático → Posse/Espaço reduzido → Finalização → Condicionamento → Recuperação.

## Academia
Mobilidade → Core/Preparação → Mini Band → Musculação → Cardio → Recuperação.

## Compatibilidade
Mantém token individual do Athlete, Firebase `procoachoficial`, rotinas V6.5 e Match Day 2.0.5.2.

## Publicação
Substitua os arquivos da raiz pelo conteúdo deste pacote. Reaplique `firestore.rules` apenas se necessário; as regras são as mesmas da 2.0.5.2 estável.
