# ProCoach 2.0.6.6 - Ficha Premium Final

Versão de fechamento da ficha Campo + Academia.

## Regras oficiais
- Uma única imagem principal por exercício.
- A galeria da Biblioteca pode continuar armazenando várias imagens, mas a ficha usa apenas a capa/principal.
- Campo prioriza imagem grande, prescrição ao lado e correções em faixa inferior.
- Academia usa uma imagem/miniatura por exercício e tabela técnica para musculação quando apropriado.
- A impressão Premium é aberta em uma janela isolada contendo apenas a ficha, evitando cabeçalho do app, primeira página vazia e sobra de página escura.
- Fallback de CSS também oculta o chrome do aplicativo caso pop-up esteja bloqueado.
- Exercícios não são divididos ao meio entre páginas.
- Quando o conteúdo não cabe, continua na página seguinte sem reduzir excessivamente a imagem.

## Publicação
Substitua os arquivos da raiz pelos arquivos deste pacote. O service worker usa o cache `procoach-2066-ficha-premium-final`.
